A lesson-planning and presentation tool

CFI Presentations

A locally run application designed to help helicopter flight instructors plan structured lessons, develop clear teaching material, and publish editable presentations to Google Slides.

What it does

  • Organizes lesson objectives and completion standards into a teachable sequence.
  • Creates slide-by-slide teaching plans with speaker scripts, instructor cues, questions, and source references.
  • Uses selected reference presentations to guide teaching style and visual design.
  • Builds editable presentation elements and can publish the reviewed result to the connected user's Google Drive as a Google Slides presentation.

Designed for instructor review

The application is a lesson-development aid. It does not replace an instructor's judgment, current FAA publications, aircraft flight manuals, approved weight-and-balance data, or applicable regulations. Instructors must verify technical claims, source applicability, aircraft-specific figures, and completion-standard coverage before teaching or using material operationally.
